О проекте

🎯 Цель проекта

Формирование у учащихся устойчивого интереса к физической культуре и здоровому образу жизни через изучение спортивного наследия родного края с использованием современных интерактивных технологий (динамической карты).

📋 Задачи

  • Систематизировать знания о спортивных объектах и выдающихся спортсменах Жлобинщины.
  • Реализовать межпредметные связи (физкультура, история, география, информатика).
  • Разработать интерактивные задания и тесты для проверки теоретических знаний по физкультуре.
  • Подготовить методические рекомендации для педагогов.
  • Обеспечить возможность интеграции с ЕИОР (eior.by).

Учащимся: Теория и практика

Изучи правила, технику безопасности и подводящие упражнения из школьной программы.

🤸‍♂️ Гимнастика и акробатика

Основные понятия:

Строевые упражнения, акробатика (кувырки, стойки, мосты), опорные прыжки. Гимнастика формирует правильную осанку и вестибулярный аппарат.

Подводящие упражнения (5-9 класс):

  • Для кувырка вперед: группировка сидя, перекаты на спине (вперед-назад).
  • Для стойки на лопатках: поднимание прямых ног из положения лежа, удержание «березки».
  • Для моста: прогибания лежа на животе, подъем таза из положения лежа.

Правило безопасности: страховка и самостраховка обязательны!

🏃‍♂️ Легкая атлетика

Основные понятия:

Бег (спринт 30/60/100 м, кросс), прыжки (в длину, в высоту), метание. Развивает быстроту, выносливость и силу.

Подводящие упражнения:

  • Для спринта: бег с высоким подниманием бедра, семенящий бег, выбегание с низкого старта.
  • Для прыжка в длину: отталкивание одной ногой с продвижением вперед, прыжки на одной ноге.
  • Для метания: имитация замаха, броски набивного мяча (или легкого предмета) из-за головы.
🏐 Спортивные игры

Основные понятия:

Баскетбол, волейбол, футбол. Развивают тактическое мышление и командный дух.

Подводящие упражнения:

  • Баскетбол: стойка баскетболиста, передачи мяча в парах на месте и в движении, ведение мяча «змейкой».
  • Волейбол: верхняя и нижняя передача мяча над собой, имитация подачи, броски мяча через сетку.
🎿 Лыжная подготовка

Основные понятия:

Попеременный и одновременный ход, спуски, подъемы, торможение. База для развития выносливости зимой.

Подводящие упражнения:

  • Для скольжения: упражнение «самокат» (скольжение на одной лыже, отталкиваясь другой).
  • Для поворотов: переступание на месте, поворот переступанием вокруг пяток.
  • Для спусков: основная стойка (ноги полусогнуты, руки с палками впереди).
